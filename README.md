# Real-Time Facial Emotion Detection Using Deep Learning

## About the Project
This project detects human facial emotions in real time using Deep Learning and Computer Vision. It uses a Convolutional Neural Network (CNN) and the FER-2013 dataset to classify facial expressions.

## Technologies Used
- Python
- TensorFlow and Keras
- OpenCV
- CNN (Convolutional Neural Network)
- Tkinter
- FER-2013 Dataset

## Key Features
- Real-time facial emotion detection using a webcam
- Face detection and emotion prediction
- Graphical user interface
- Model training and evaluation scripts

## Project Structure
- `notebooks/` — Exploratory data analysis
- `src/data_preprocessing.py` — Data preprocessing
- `src/model.py` — Model implementation
- `src/train.py` — Model training
- `src/evaluation.py` — Model evaluation
- `src/real_time_detection.py` — Real-time detection
- `src/ui_app.py` — Graphical user interface
- `requirements.txt` — Python dependencies

## Installation and Setup

1. Clone this repository.
2. Open the project folder in VS Code.
3. Create and activate a Python virtual environment.
4. Install the dependencies:

```bash
pip install -r requirements.txt
```

5. Prepare the FER-2013 dataset locally.
6. Train the model and follow the scripts in `src/` to run the application.

**Note:** The dataset and trained model weights are not included in this repository. You may need to train the model before running the application.
